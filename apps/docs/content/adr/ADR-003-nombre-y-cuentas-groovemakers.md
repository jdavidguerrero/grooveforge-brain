# ADR-003: Nombre del canal y cuentas — GrooveMakers con groovemakers.co

**Status:** Accepted
**Date:** 2026-10-22
**Deciders:** Juan Guerrero
**Relacionados:** ADR-002 (comunidad primero), `00-master-strategy.md` §8.1 (ecosistema de marca)

---

## Context

- El canal de YouTube y la comunidad se iban a llamar **GrooveMakers** (`00` §8.1), dentro de la familia GroovePilot /
  GrooveForge.
- El usuario `@groovemakers` ya está tomado en redes.
- Juan es dueño del dominio **groovemakers.co** (renovación ≈ 214.000 COP / año).
- Existe una app antigua de IK Multimedia llamada **GrooveMaker** (singular, desde 1998; versiones móviles hasta
  2015), en el mismo rubro.

## Verificación hecha (2026-10-22, preliminar, no es asesoría legal)

| Base | Búsqueda | Resultado |
|---|---|---|
| SIC Colombia (SIPI, consulta gratuita) | GROOVE / GROOVEMAKER / GROOVEMAKERS | **Sin resultados**, ni siquiera con "groove" |
| OMPI, Global Brand Database | las mismas variantes | Solo marcas genéricas con "groove"; **nada parecido a GrooveMakers** |
| Web | "GrooveMakers" música | Solo la app GrooveMaker de IK Multimedia (sin registro de marca encontrado) |

## Decision

1. **El canal se llama GrooveMakers.** Se mantiene la familia: GroovePilot (IA), GrooveForge (hardware),
   GrooveMakers (canal y comunidad).
2. **Se renueva groovemakers.co** y se usa como ancla: web futura, correo propio para la lista
   (por ejemplo `juan@groovemakers.co`) y nombre de usuario.
3. **Usuario de las cuentas, igual al dominio:** `@groovemakers.co` en Instagram (acepta puntos);
   `@groovemakersco` en YouTube y TikTok, donde el punto no está disponible o confunde. Reservar los que estén libres
   aunque no se usen todavía.
4. **Reparto de cuentas:** YouTube es de GrooveMakers; Instagram es la cuenta personal de Juan (los Reels llevan el
   sello pequeño de GrooveMakers y el link al canal). La cuenta `@groovemakers.co` de Instagram se reserva y puede
   quedar como redirección a la personal.
5. **No se registra la marca todavía** (ADR-002: sin venta). Si el canal crece o se vende algo con el nombre, el
   primer paso es registrar GrooveMakers en la **clase 41** (y 9 / 15 si hay productos) ante la SIC, con revisión
   de un abogado de propiedad intelectual.

## Consequences

- Nada de lo ya escrito cambia de nombre (Biblia, guiones, prompt de marca).
- El nombre GrooveForge (hardware) tiene coincidencias en apps de música (una app de teclado MIDI para Android, un
  proyecto de música con IA). No bloquea nada mientras no haya venta; revisar antes de comercializar.

## Action Items

1. [ ] Renovar groovemakers.co (comparar precio con otros registradores; transferir en la próxima renovación si
   conviene).
2. [ ] Reservar `@groovemakers.co` (Instagram) y `@groovemakersco` (YouTube, TikTok).
3. [x] Prompt de marca con el usuario y el dominio: `../marca/claude-design-prompt-groovemakers.md`.
