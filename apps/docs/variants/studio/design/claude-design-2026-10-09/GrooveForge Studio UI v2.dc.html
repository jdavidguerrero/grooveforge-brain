Row 1 keeps v1 geometry so B1–B4 stay under their keys and existing soft-key code is unchanged.
Row 2 is 32 px and display-only: MODE, NAV and B6 are physical buttons, and 32 px is under the 64 px touch minimum. Touch shortcuts remain on row 1 soft-keys and in content.
P1 and P2 are 224 px wide and pinned to the left and right screen edges, the closest points to the knobs, which sit outside the display width. ENC L and ENC R are pinned the same way in row 1, so each side column reads encoder above pot, matching the panel.
P blocks: tag T12/600 · label T12 · value T16/600 · 2 px value bar inset 16. P2 is mirrored so its tag sits on the outer edge.
Repaint cost: P block 224×32 on pot change (≤30 Hz). SHIFT/HOLD changes repaint two P blocks and one 112×32 cell.
