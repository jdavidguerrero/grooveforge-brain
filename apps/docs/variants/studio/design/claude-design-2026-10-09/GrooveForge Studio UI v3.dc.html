CONFLICTS WITH V3 · NOTED, NOT RESOLVED
1 · The control tables name OSC SHIFT P1 / P2 OCTAVE / MIX. No engine implements OCTAVE in firmware; the page uses engine-named slots instead. Detune is shown in cents, intervals in semitones.
2 · Note 03a says B2 returns to PERFORM. This brief says the key returns to the last view (PERFORM / AI / SPECTRUM). OSC and LFO notes follow the brief; 03a is unchanged.
3 · PERFORM P2 is LFO → CUTOFF, but the firmware has no LFO yet, so that control has nothing to drive until the LFO lands. Once it does, PERFORM P2 and LFO P2 (destination CUTOFF) write the same value: lfo.depth[CUTOFF].
4 · v3 defines NAV push as “action”. On OSC it has no function; on LFO it toggles SYNC. NAV cell labels gain OSC, OP, NONE and PUSH SYNC.
5 · On DX7, SHIFT ON swaps the graph for the algorithm picker (11c2). Everywhere else SHIFT only swaps the active pair.
6 · LFO / MOD second layer: when it exists it would be the NAV-turn target on this page (LFO ↔ MOD), with a layer tab in the header row left of the shape chips. Not designed.
